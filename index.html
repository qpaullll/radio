Подсказки
  • Телефон: держи эту страницу открытой — экран не будет гаснуть, пока играет радио. Если свернуть браузер, ведущий замолчит.
  • Spotify на телефоне: сначала открой приложение Spotify и включи любой трек на пару секунд — тогда телефон появится в списке устройств.
  • Spotify: читаются только плейлисты, которые ты создал сам или где ты соавтор (ограничение Spotify).
  • YouTube: плеер берёт до 200 видео из плейлиста; видео, которые запрещено встраивать, пропускаются. На iPhone иногда нужно один раз нажать ▶ в самом видео.
  • Живой голос бесплатно: на компьютере открой сайт в Microsoft Edge и выбери голос с пометкой «Online (Natural)». На iPhone: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → скачай улучшенный голос.
